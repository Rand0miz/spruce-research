# Benchmark artifacts

`paper_results/natural_yarn_beam16/` contains the immutable report, tables,
and publication-ready figures from the fully charged dense-versus-compiled
comparison. `prompt_banks/` contains the sealed prompt-bank specification used
by that run.

The result card states the hardware, model, configuration, scope, and
limitations that must accompany any quoted number. The research repository
retains the larger experiment harness and raw run archives; these are excluded
from the installable package and release ZIP so that the public toolkit remains
small and free of checkpoints.
